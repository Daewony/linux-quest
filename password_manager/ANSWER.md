# パスワードマネージャー 実行結果

## ステップ1：パスワードの保存

サービス名、ユーザー名、パスワードを入力し、`password.txt` に保存されることを確認しました。

**入力したテストデータ**

| サービス名 | ユーザー名 | パスワード |
| ---------- | ---------- | ---------- |
| a          | b          | c          |
| Google     | user1      | test123    |

**保存結果**

`cat password.txt`

```text
a:b:c
Google:user1:test123
```

既存のデータが上書きされず、新しいデータが追記されることを確認しました。

## ステップ2：メニュー機能

### 1. Add Password

メニューで `Add Password` を選択し、以下のデータを入力しました。

- サービス名：`d`
- ユーザー名：`e`
- パスワード：`f`

**実行結果**

```text
パスワードの追加は成功しました。
```

`password.txt` に新しいデータが追加されました。

```text
a:b:c
Google:user1:test123
d:e:f
```

### 2. Get Password（登録済み）

メニューで `Get Password` を選択し、サービス名に `Google` を入力しました。

**実行結果**

```text
サービス名: Google
ユーザー名: user1
パスワード: test123
```

登録済みのサービス情報を正しく取得できることを確認しました。

### 3. Get Password（未登録）

メニューで `Get Password` を選択し、登録されていないサービス名 `qwer` を入力しました。

**実行結果**

```text
そのサービスは登録されていません。
```

未登録のサービスに対して、適切なメッセージが表示されることを確認しました。

### 4. メニューにない入力

メニューで `add` と入力しました。

**実行結果**

```text
入力が間違えています。 (Add Password/Get Password/Exit)から入力してください。
```

指定されたメニュー以外の入力に対して、エラーメッセージが表示されることを確認しました。

### 5. Exit

メニューで `Exit` を選択しました。

**実行結果**

```text
Thank you!
```

終了メッセージが表示され、プログラムが終了することを確認しました。

また、`Add Password` や `Get Password` の処理後もメニューに戻り、続けて操作できることを確認しました。
